2. Audit Categories

2.1 Technical SEO

Score: 78/100

What Works

  • HTTPS+HSTS, CSP, security headers complete
  • 301s for http/www/trailing slash/uppercase; canonical strips query
  • robots.txt served by Node; sensitive surfaces disallowed
  • Valid sitemap index, 187 children, lastmod
  • Bots get 404 for missing pages; SSR TTFB 0.30-0.41 s
  • hreflang 46 languages + x-default, reciprocal

Findings

Sitemap lists 1,316,781 URLs; episode family ~1.2M across 46 languages High

GSC memory: episode family ~4% indexed. User decision (5 Sep) keeps all 46 languages; monitor gap between submitted and indexed.

Recommendation: Apply content-based noindex gate (see Content #1) rather than language-based cuts; watch indexed/submitted ratio.

Dynamic rendering by User-Agent is the only path to indexable HTML Medium

Human UA receives 12.9 KB Flutter shell with generic title; bots receive SSR. nginx bot regex is a single point of failure (3 Sep regex bug dropped SEO tools to shell).

Recommendation: Add regression test for the UA matrix after every deploy; long-term serve SSR to everyone with Flutter hydrating on top.

Human UA gets HTTP 200 for non-existent paths (soft 404) Medium

/olmayan-sayfa-xyz123 returns 200 + shell for humans; Googlebot gets 404.

Recommendation: Return 404 status with the shell or an nginx 404 page for unknown routes.

Sub-sitemaps not cached at the edge Medium

cf-cache-status DYNAMIC; gzip 123 KB/1.0 s, uncompressed 3.2 MB/10-27 s.

Recommendation: Cloudflare Cache Rule: /sitemap*.xml eligible, 1h edge TTL.

No llms.txt Low

Bot UA 404, human UA shell 200. Optional; ignored by Google.

Recommendation: Optional: serve plain text on the SSR route.

document.title stays 'dizi.jpg' on every page in the Flutter app Low

Playwright: title unchanged after render on / and /icerik/tv/1405.

Recommendation: Set page title from Flutter router for bookmarks/sharing.

2.2 Content Quality

  • Person pages already noindex when biography missing in that language

Findings

Episode pages in low-resource languages are template filler High

/sw, /am, /hi episode pages: no episode title or summary (no TMDB translation); 193-214 words all boilerplate; indexable and in sitemap (~1M URLs).

Recommendation: Content gate identical to person pages: if episode title OR summary missing in that language → noindex,follow and drop from sitemap. Not a language cut; tr/en/de unaffected.

Translation leaks Medium

/sw/sirket/4343 contains Turkish 'Öne çıkan yapımları:'; genres untranslated on sw/am series pages; '@dizi.jpg.ai dizi.jpg AI özeti' Turkish on /en.

Recommendation: Add leak scan across 46 languages for Turkish tokens; translate genre names.

Meta descriptions end mid-sentence with '…' Medium

e.g. '...Miami'de…', '...atom…'.

Recommendation: Truncate at sentence boundary.

Homepage H1 is brand only Low

H1 'dizi.jpg' while title carries the keyword.

/kesfet titled 'Ana Sayfa — dizi.jpg' Low
